Robot Controls Cheat Sheet
Controller Control (Standard / PS) Function Hardware Name(s)
Driver (GP1) Left Stick Drive / Strafe front_left_drive, back_left_drive, front_right_drive, back_right_drive
Right Stick Turn front_left_drive, back_left_drive, front_right_drive, back_right_drive
D-Pad Up / Down Adjust Roller Bed Speed left_roller_bed_servo, right_roller_bed_servo
Y / ▲ Cycle Feeder Direction (Off/Fwd/Rev) left_feeder_servo, right_feeder_servo
Start / Options Full System ON (Shooter & Intake) flywheel_1, flywheel_2, booster_servo, intake_roller, all_servos
Back / Share Full System OFF (Shooter & Intake) flywheel_1, flywheel_2, booster_servo, intake_roller, all_servos
Operator (GP2) Left Stick Up / Down Adjust Shooter Angle shooter_servo
Right Stick Left / Right Manual Turret Rotation turret_servo, turret_encoder
D-Pad Up / Down Adjust Flywheel RPM flywheel_1, flywheel_2
D-Pad Left / Right Adjust Booster Speed booster_servo
Right Bumper (R1) Toggle Shooting Mode (Preload/Manual) -
Right Trigger (R2) Pull Trigger (Shoot Pre-loaded Ball) booster_servo, left_feeder_servo, shooter_beam_sensor
Left Bumper (L1) Gates to Pass-Thru (Hold) left_gate_servo, mid_gate_servo, right_gate_servo
Y / ▲ Toggle Intake Roller intake_roller
X / ■ Manual Open Left Gate left_gate_servo
A / ✖ Manual Open Mid Gate mid_gate_servo
B / ● Manual Open Right Gate right_gate_servo
Options / Start Cycle Turret Aim Mode (Manual -> Red -> Blue) limelight, turret_servo
Back / Share Cycle Debug Mode flywheel_1/2, left/mid/right_color_sensor, limelight, etc.

Initial State at Match Start

  • Drivetrain: Ready.
  • Intake System: Intake Roller is ON. Feeder servos are REVERSED.
  • Gates: All three gates are CLOSED.
  • Shooter Assembly: Turret is centered. Shooter angle is at default. Flywheel target is 500 RPM.
